02 // AGENT DESIGN
Six specialist agents
P0 · ORCHESTRATOR
Workflow Coordinator
Dispatches tasks, aggregates results, validates outputs, and enforces the human approval gate before any report reaches stakeholders.
READ WRITE RESTRICTED ZONE
P1 · ASSET CONTEXT
Asset Criticality Classifier
Queries CMDB with scoped credentials. Classifies each in-scope asset as High, Medium, or Low criticality. Never exports full inventory.
READ RESTRICTED ZONE
P2 · VULNERABILITY
CVE Scorer
Fetches CVE records from NVD and CVSS API. Correlates to asset list from Orchestrator. Cross-validates scores against NVD baseline.
READ EXTERNAL ACCESS
P3 · THREAT INTEL
TTP Mapper
Ingests allowlisted TI feeds. Maps adversary techniques to MITRE ATLAS IDs. Cross-validates across two independent sources before accepting any TTP.
READ EXTERNAL ACCESS
P4 · CONTROL MAPPING
Gap Analyst
Maps identified risks to NIST RMF control families and OWASP LLM Top 10 categories. Validates control IDs against the official SP 800-53 catalog.
READ INTERNAL
P5 · REPORT GENERATOR
Report Compiler
Compiles risk register, executive summary, and CSV export. Hashes and signs draft. Submits to human approval queue. Cannot self-deliver.
READ WRITE INTERNAL
